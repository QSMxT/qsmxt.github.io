The QSMxT Ecosystem

Turn MRI phase into susceptibility maps: reconstruct in your browser with QSMbly, or process a whole study from the command line with QSMxT. Both are built on QSM.rs, a Rust library with 40+ algorithms, and QSM-CI shows you how those methods and others actually perform. All free and open source.

QSM.rs
Library

Every stage of the reconstruction, from brain extraction to dipole inversion, in one Rust crate. QSMxT and QSMbly both run this code.

Explore the library →
QSMxT
Pipeline

A command-line tool and interactive TUI that takes BIDS or raw DICOM data to susceptibility maps. One binary, built for batch processing and clusters.

Browser app
